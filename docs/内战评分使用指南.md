# LOL Stats 内战评分模块使用指南（v1.0）

> 本指南面向第一次使用 LOL Stats 的玩家。内战评分是本软件专门为**自定义 5V5 内战**设计的统计模块，
> 用来汇总每场内战、每位玩家的表现数据，帮大家赛后复盘、互相"查成分"。

---

## 一、使用前提

1. 系统：Windows 10 / 11 64 位。
2. **先登录国服英雄联盟客户端，再启动 LOL Stats**（软件通过本机客户端读取战绩，不登录会提示连接失败）。
3. 安装包：`lol-stats_1.0.0_x64-setup.exe`，正常安装后双击运行即可，无需管理员权限。

---

## 二、进入内战评分

打开软件后，点击左侧导航的 **"内战评分"** 页面。

### 顶部工具栏（从左到右）

| 控件 | 说明 |
| --- | --- |
| 日期区间 | 手动选择起止日期（含当天） |
| 快速时间范围 | 今日（默认）/ 本周（周一为起点）/ 本月 / 三个月内 / 全部对局（近 5 个月）；选择后自动刷新 |
| 仅显示内战 | 开启时只统计自定义模式（队列 3270）对局；关闭则包含当天所有模式 |
| 5V5 | 开启时只统计双方各 5 人的完整对局 |
| >8min | 开启时过滤不足 8 分钟的对局（避免速投、重开污染数据） |
| 场数≥ | **全局玩家样本门槛**：只统计场数达到该值的玩家，影响汇总卡、图表、雷达、荣誉墙、趋势与对比；对局列表、阵容搭档、英雄/装备榜不受影响。留空 = 不限 |
| 刷新 | 重新拉取当前区间的对局数据 |

> 提示：鼠标悬停在任意按钮上会显示它的作用说明。

---

## 三、汇总卡

数据加载后，页面顶部会显示当前区间（符合过滤条件）的整体情况：

- 总对局、总人数、平均胜率、均分、平均 KDA、蓝方胜场、红方胜场；
- 位置分布（各位置的玩家数量占比）；
- 标签统计（出现最多的玩家标签及次数）；
- 评级分布（六个评级的人数比例）。

### 评级与分数口径（娱乐性，非官方）

| 评级 | 综合分 |
| --- | --- |
| 通天代 | ≥ 90 |
| 小代 | ≥ 80 |
| 小有实力 | ≥ 70 |
| 普通人 | ≥ 60 |
| 小坑比 | ≥ 40 |
| 大坑比 | < 40 |

- **高光局**：单局评分 ≥ 80；**战犯局**：单局评分 < 60。
- 评分是软件根据 KDA、伤害占比、经济转化、承伤、治疗控制等综合计算的娱乐数据，不代表官方水平认定，请勿用于人身攻击。

---

## 四、对局列表

- 点击 **"对局列表"** 标题整行可展开/收起；
- 每张对局卡片：蓝红双方 5 人（头像 + 名字 + 单局评分）、中间显示队列、时长、全场 **MVP**、双方均分对比；
- 卡片右上角标签：**速推局**（<15 分钟）、**拉锯局**（>24 分钟）、**碾压局**（双方均分差 ≥ 12）；
- **点击卡片展开单局十人明细**：召唤师技能、装备、符文/海克斯、K/D/A、切C、伤害/经济/承伤/治疗护盾（含占比）、伤转、单局评分；
- 卡片右下角 **× 可删除该局**（如误记、重开局等），删除后顶部会出现"已删除 N 局 · 恢复"按钮，一键恢复。

---

## 五、玩家评分表（核心）

按玩家聚合当前区间内的表现。默认已展开"详细"与"效率"两组列。

### 主要列

| 列 | 说明 |
| --- | --- |
| 玩家 | Riot ID；**点击整行打开右侧玩家详情抽屉**，点空白处关闭 |
| 场 / 胜 / 胜率 | 出场场次、胜场、胜率 |
| 击杀 / 死亡 / KDA | 场均数据 |
| 输出 / 前排 / 辅助 | 三项能力分（0-100） |
| 详细组 | 伤害%、承伤%、治疗/护盾%、转化；伤害/承伤/助攻榜首次数（悬停显示具体对局） |
| 效率组 | 分均经济、分均伤害、分均补刀、参团率、击杀占比、承伤每死 |
| 高光 / 战犯 | 高光局数（≥80 分）/ 战犯局数（<60 分） |
| 综合 | 综合分（多局均值） |
| 评级 | 见上表 |

### 操作

- **排序**：点击任意列标题切换升/降序；
- **极值高亮**：开启后每列最好值绿框、最差值红框（死亡、战犯为反向指标）；
- **搜索**：按玩家名过滤；
- **展开详细 / 展开效率**：显示/收起两组附加列（默认展开，生效时按钮为紫色）；
- **导出图片**：
  - 评分面板（全部玩家）：PNG / JPEG / WebP × 2x / 3x，白底清晰大图；
  - 玩家详情页（每人一张，打包 ZIP）：把所有玩家的详情页图片打包成一个 ZIP（PNG 2x / 3x），适合直接发群。

## 六、数据可视化

- **玩家综合分**：条形排名，点击条查看该玩家详情；
- **玩家胜率榜**：按胜率排序，绿≥50%、红<50%；
- **英雄出场 TOP**：出现次数最多的 10 个英雄（含胜率）；
- **评分 × 胜率散点图**：横轴综合分、纵轴胜率、气泡大小 = 场次，看"分高的人是不是真能赢"；
- **蓝红方胜场**：双方胜场与占比。

点击条形/散点只会在右侧弹出玩家详情，**不会跳走当前视图**。

---

## 七、玩家能力雷达

- 在下拉列表中勾选一个或多个玩家，叠加对比六维能力（输出、承伤坦度、团队功能、团战稳定、击杀收割、胜负贡献）；
- "显示全员平均雷达"可叠加灰色平均基准；悬停雷达图可看各项数值；
- 支持画布尺寸切换（小/中/大）、"仅显示轮廓模式"、"导出图片"（复制到剪贴板）；
- "最低参赛场次阈值"可过滤掉场次太少的玩家。

---

## 八、荣誉墙 / 玩家状态趋势 / 选手对比

### 荣誉墙
每局全场 10 人评选 7 类荣誉（MVP、伤害王、承伤王、助攻王、经济王、KDA王、控场王），展示每类前 3 名。

### 玩家状态趋势
- 选择玩家后查看其按时间排列的每局表现折线：绿点 = 胜、红点 = 负、橙虚线 = 近 5 局均线；
- 纵轴指标可切换：评分 / KDA / 伤害占比 / 分均伤害（纵轴自动适配数据）；
- **悬停数据点**：显示时间、时长、英雄、K/D/A、胜负、指标值；
- **点击数据点**：直接展开并跳转到对局列表中的那一局。

### 选手对比（A vs B）
- 选择两位玩家（不允许选同一人，会自动错开）；
- 摘要卡：场次、胜率、均分、KDA、波动率、高光率、战犯率等；
- 能力雷达叠加图：紫=A、黄=B，悬停顶点查看原始数值；
- 逐项指标对比：12 项指标成对条形，优势方高亮（场均死亡为反向）；
- 交手记录：同队/对位场次与胜率 + 最近 10 局明细。

---

## 九、阵容与搭档 / 玩家组队搭档统计

### 阵容与搭档
- 五人固定阵容、双人搭档、三人搭档三张表；
- 每组都有独立的"场次≥ / 胜率≥"筛选，表头可排序。

### 玩家组队搭档统计
- 选择目标玩家，切换"搭档"（同队）或"对位"（对手）模式；
- 表格显示共同场次、胜场、胜率、近 5 场胜负圆点；
- 支持"共同场次≥ / 胜率≥"筛选，**点击任意行可切换目标玩家**。

---

## 十、英雄榜 / 海克斯榜 / 装备榜

### 英雄榜
- 搜索英雄、按"次数≥"过滤、按次数/胜率排序；
- 显示最喜欢使用、胜率最高/最低的玩家（可设置局数门槛）；
- **点击英雄行打开详情抽屉**：
  - 概览、出场日期（如 2026/8/31）、使用玩家、召唤师技能、核心装备；
  - **对局明细**：每行显示该局玩家名、蓝红、胜负、KDA、时长、伤害占比、评分；
  - **点击某场对局**：侧边栏左侧弹出本局十人详细对战（MVP、双方均分、装备符文、切C、伤转等），点击其它对局直接切换，再点当前对局或点 × 关闭。

### 海克斯榜 / 装备榜
- 搜索、次数门槛、按次数/胜率排序；
- 装备榜支持"仅成装"过滤。

## 十一、玩家详情抽屉

点击评分表任意玩家行打开，包含：

- 综合概览（综合分/评级/中位分/波动率/高光率/战犯率）；
- **最近 5 局**：胜负小格 + 单局评分，最新一局带描边；
- **位置分布**：各位置场次占比与胜率 + 主定位；
- 战绩与 KDA、能力三围；
- 效率与占比（分均经济/伤害/补刀、参团率、击杀占比、承伤每死、伤害/承伤/治疗护盾占比、伤转）；
- 荣誉与榜首、标签、英雄详情；
- 右上角可**导出该玩家的详情图片**（PNG/JPEG/WebP × 2x/3x）。

## 十二、常见问题（FAQ）

**Q1：页面提示连接失败 / 没有数据？**
先确认已登录国服客户端再打开软件；当天没有打自定义内战也会没有数据。可关掉"仅显示内战"看看是否有其它模式对局。

**Q2：评分表为空？**
检查顶部"场数≥"是否设得太大（如 5），把它清空或调低即可；也可看看日期区间是否正确。

**Q3：为什么对局列表有局、评分表里少了一些玩家？**
玩家被"场数≥"门槛过滤了；对局列表本身不受该门槛影响。

**Q4：删除的对局能找回吗？**
可以。删除后顶部会出现"已删除 N 局 · 恢复"按钮，点击即全部恢复。

**Q5：选"本周"为什么显示"今日"？**
旧版本在周一会出现该问题，v1.0 已修复：下拉框会记住你选的是"本周"。

**Q6：导出的图片/ZIP 保存在哪里？**
导出时弹系统保存对话框，自己选择路径；ZIP 解压后是每名玩家一张 PNG。

**Q7：评分/评级是不是官方数据？**
不是。所有评分、标签、评级都是软件根据对局数据计算的娱乐性分析，仅用于内战复盘和互损（请文明使用）。

---

## 十三、安全与隐私

- 软件只读取本机客户端提供的数据，不修改任何对局数据；
- 战绩数据来源于你已登录的客户端账号，请勿把包含他人隐私信息的截图/文件公开发布。
